# 豆瓣书影标签 douban-tags

在豆瓣页面点一下插件图标，右侧打开一个面板，**按标签筛选你想读、想看、读过、看过的书和电影**。

- 不用手动打标签：根据豆瓣列表页上的信息自动整理出类型、国家/地区、语言、年代、演员、导演、作者、出版社、评分、时长等标签
- 多选取交集：例如"韩国 + 历史 + 想看"
- 书和电影可以分开看，也可以合在一起看
- 你在豆瓣上手打过的标签也会保留
- 打开面板时自动在后台同步：新标记、状态变化、删除和修改都会同步过来
- 书的作者没标国籍时，查维基百科判断文化归属（中国大陆 / 中国台湾 / 中国香港 / 外国）
- 书的题材（小说、传记回忆录、历史、女性主义……）根据豆瓣成员常用标签自动归类，小说、历史等还细分二级（推理悬疑、科幻、中国近现代史……）；评价人数少的书标为"冷门书"
- 可选 AI 归类：填一个 DeepSeek API Key，书的题材改由大模型判断（更准）；不填就用关键词规则
- 数据只存在你自己的浏览器里，默认不需要账号或 API key

> 当前是 0.5 版本。

## 安装（Chrome / Edge）

1. 下载本仓库：点右上角绿色的 **Code → Download ZIP**，然后解压
2. Chrome 地址栏打开 `chrome://extensions`（Edge 打开 `edge://extensions`）
3. 打开右上角的 **开发者模式**
4. 点 **加载已解压的扩展程序**（有的 Chrome 版本叫"加载未打包的扩展程序"），选择解压出来的 `douban-tags` 文件夹
5. 点浏览器工具栏的拼图图标，把"豆瓣书影标签"固定到工具栏

## 使用

1. 在这个浏览器里登录豆瓣
2. 打开任意豆瓣页面，点插件图标，右侧会打开"书影分类"面板
3. 第一次使用点 **开始读取**。插件会逐页读取你的清单，每页之间随机等待 2–5 秒，每 10 页休息 30 秒，以免被豆瓣限流。1000 条左右的记录大约需要 5–10 分钟，期间请保持面板开着
4. 读取完成后，点标签就能筛选

中途关闭面板也没关系，下次打开会从上次停下的地方接着读。

### 自动同步

以后每次打开面板，插件会在后台自动同步，进度只在面板底部显示一行小字：

| 变化 | 怎么同步 |
|---|---|
| 新标记、状态变化（想看 → 看过） | 打开面板时自动"更新"，只读每个清单最新的几页（两次之间至少隔 30 分钟） |
| 在豆瓣上删除了条目 | 更新时对比每个清单的总数，对不上就只重读那一个清单 |
| 修改了旧记录的评分、标签 | 每两周在后台完整重读一次 |

面板底部的 **更新**、**全部重读** 可以随时手动触发。

## 标签是怎么来的

豆瓣列表页里每一条都带一行简介，插件从这行文字里拆出字段：

| | 简介里的内容 | 拆出来的标签 |
|---|---|---|
| 电影 | 上映日期 / 演员 / 国家 / 导演 / 时长 / 片名 / 类型 / 编剧 / 语言 | 类型、国家、语言、年代、演员、导演、时长 |
| 书 | 作者 / 译者 / 出版社 / 出版日期 / 价格 | 作者国籍（如 [美]）、作者、出版社、年代 |

演员和导演是按位置推断的，个别格式特殊的条目可能分错。

### 书籍题材和冷门书

列表页上没有题材信息，插件会在后台逐本读取书籍详情页（防封速度，第一次约半小时，以后只读新书），取出两样东西：

- **豆瓣成员常用标签**（详情页脚本里的 `criteria`）：去掉作者名、书名、国家、空泛词后，显示在"豆瓣标签"分组；再按 `app/topic-rules.js` 里的题材词表归并，显示在"题材"分组。一本书可以属于多个题材
- **评价人数**：少于门槛的书，在"题材"里归为"冷门书"

改题材词表或冷门门槛后刷新面板即可生效，不需要重新读取豆瓣。

**二级题材**：小说、历史、传记回忆录、艺术、经济管理、科普在"题材"里点选后，下面会展开一行二级：

| 一级 | 二级 |
| --- | --- |
| 小说 | 推理悬疑、科幻、奇幻、历史小说、爱情、武侠、网络小说、短篇集 |
| 历史 | 中国古代史、中国近现代史、世界史、战争军事、海外中国研究、社会文化史、史学理论 |
| 传记回忆录 | 自传回忆录、人物传记、日记书信 |
| 艺术 | 美术绘画、摄影、建筑园林、音乐、戏剧、设计、美学 |
| 经济管理 | 经济学、金融投资、商业管理 |
| 科普 | 数学统计、物理、生物演化、医学、天文宇宙、科学史 |

- 选了二级，这个一级就只看选中的二级；同一行多选是"任意一个"
- 哪个二级都没命中的书归入"其他"（多半是豆瓣上只被标了"小说""历史"这类总称）
- 国别不做二级，用"国家 / 地区"分组组合筛选，例如 小说 + 日本
- 社会学、哲学、政治、心理学暂不细分：一半以上的书只有总称标签，拆出来大多会落进"其他"

**上下册统一**：书名去掉"上/下""（一）""第 2 部"这类卷次后相同、作者也相同的书，题材合并成一组。

已知限制：每本书的豆瓣标签目前只读一次，之后别人补的标签不会自动进来（计划在下一版定期重读）。

### AI 归类（可选）

关键词规则分不清"讲医生的小说"和"医学科普"，也给不了没有标签的冷门书。填入大模型的 API Key 后，书的题材改由 AI 判断：

1. 到 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 注册、充值、创建 API Key（几百本书归类一次大约几分钱，以[官方价格](https://api-docs.deepseek.com/quick_start/pricing)为准）
2. 面板底部点 **AI 归类**，粘贴 Key，点 **保存并开始**
3. 插件把**书名和作者**分批发给 AI（每次 10 本），AI 只能从固定的一级/二级题材清单里选，结果存在本地；以后只问新书
4. AI 拿不准的书仍用规则；点 **关闭 AI** 随时切回规则；**导出对比表** 可以下载一份 CSV，逐本对比规则和 AI 的结果

技术细节：OpenAI 兼容接口 `POST https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`，JSON 输出模式，关闭思考模式。换别家兼容服务可在"换别的模型"里改地址和模型名，并在 `manifest.json` 的 `host_permissions` 里加上该地址。

隐私：开启后书名和作者会发送给 AI 服务商；API Key 只存在你自己的浏览器里，不会上传到其他地方。

### 书籍作者的文化归属

豆瓣上中国作者一般不标国籍。作者名前后没有国籍标注、没有译者、是不带"·"的中文名时，先记为"中国大陆"，再在后台查中文维基百科和维基数据修正：

1. **确认是哪个人**：用"作者名 + 你标记的书名"搜索；只认名字完全一致（含笔名）的人，或者书页面上记录的作者。同名的多个人里，优先选维基页面提到这本书的、简介像作家的。确认不了就不改
2. **判断文化归属**（看成长和创作的环境，不只看护照）：
   - 简介写了台湾、香港、澳门的，直接用
   - 海外华人学者，看青年时代大部分学校在哪个地区，其次看出生地
   - 简介写中国的，或国籍是中华人民共和国、清朝、民国时期（如鲁迅），记为中国大陆
   - 其他外国作者按国籍
3. **手动修正**：判断错了的，在 `app/author-overrides.js` 里加一行，优先级最高

每位作者只查一次，结果保存在本地。会访问 zh.wikipedia.org 和 www.wikidata.org，只发送作者名和书名。

## 开发

```
manifest.json       插件配置（Manifest V3，侧边栏）
background.js       点击图标时打开侧边栏
app/parser.js       从简介文字中拆出字段（纯函数，有单元测试）
app/listpage.js     解析豆瓣列表页 HTML
app/sync.js         逐页读取、限速、断点续传、增量更新、删除检测
app/details.js      读取书籍详情页（豆瓣常用标签、评价人数）
app/topics.js       标签清洗、题材归并、冷门书
app/topic-rules.js  题材词表和冷门门槛（可自己改）
app/llm.js          AI 归类（提示词、调用接口、结果校验）
app/authors.js      作者文化归属（维基百科 / 维基数据）
app/author-overrides.js  作者归属的手动修正名单
app/store.js        本地存储（chrome.storage.local）
app/ui.js           筛选界面
app/panel.html/js   侧边栏面板
tests/              解析和归属判断的测试，样本来自真实数据
```

运行测试（需要 Node.js 18+）：

```
npm test
```
